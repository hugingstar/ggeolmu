🛡️ Manager Tier Security Audit & Meta-Prompt Log Console

📌 페이지 목적: 4-Tier 아키텍처의 Manager 계층(AuditAgent & PromptMakerAgent)이 웹 사용자 종목 검색 시 발생할 수 있는 보안 취약점(SQL Injection, 프롬프트 주입 공격)과 불필요한 SPAC/ETF 종목을 1차 산출 검사한 보안 및 메타프롬프트 생성 이력 관제 페이지입니다.

💡 결과 해석 방법 (How to Interpret Logs)

  • 🟢 PASS / PASSED: 사용자 검색어가 SQL Injection 및 프롬프트 주입 공격으로부터 안전하고, SPAC/ETF 종목이 아님이 검증되어 AI 메타 프롬프트가 무사히 생성됨을 의미합니다.
  • 🔴 REJECTED / BLOCKED: 악의적인 SQL injection 구문, 프롬프트 주입 시도, 또는 분석 불필요 종목이 감지되어 Manager 계층에서 WAS/DB로 전달되기 전 사전 차단되었음을 의미합니다.
